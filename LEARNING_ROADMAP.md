# План самостоятельного разбора

1. Проследи путь запроса: `app/main.py` → router → SQLAlchemy → база данных.
2. Разбери Pydantic-схемы и HTTP-методы.
3. Изучи модели, primary key, foreign key и relationship.
4. Объясни Engine, Session, add, commit, refresh, rollback.
5. Изучи начальную Alembic-миграцию.
6. Запусти `pytest -v`, разбери фикстуры и dependency override.
7. Самостоятельно добавь фильтрацию по статусу, сортировку измерений и поле description через новую миграцию.
8. Добавляй тесты и делай отдельный Git commit для каждой доработки.

Не добавляй проект в портфолио как освоенный, пока не можешь объяснить каждый модуль и самостоятельно внести изменения.
